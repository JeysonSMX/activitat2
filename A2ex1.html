Introducció a la Programació amb Python

Python és un llenguatge de programació d'alt nivell àmpliament utilitzat en ciència de dades, intel·ligència artificial i desenvolupament backend.

A continuació es mostra un fragment de codi bàsic en Python que defineix una funció per calcular el factorial d'un nombre: 

def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * factorial(n - 1)

print("El factorial de 5 és:", factorial(5))
